# CVO3 후보 e764270의 macOS Codex 설치와 실제 eval

## Summary and Decision

**FAIL.** 무모델 신규 설치와 업데이트는 통과했다. 실제 Codex eval은 쓰기 대조군과 첫 dry-run을 통과했다. dry-run 2회차에서 도우미가 실제로 실행됐지만 호출 형식이 평가기의 허용 범위를 벗어나 실패했다. 이번 보고서는 macOS Codex의 설치와 eval을 판정한다. 전체 CVO3 필수 17개에 같은 후보의 기존 검사까지 반영하면 6개 통과, 1개 실패, 10개 미검증이다.

## Scope and Criteria

VFY-CVO-09의 비공개 Codex 신규 설치·업데이트(T10·T11)와 VFY-CVO-10의 비공개 Codex eval(T17)이 필수다. Eval은 쓰기 대조군 1턴과 3개 사례 각 3턴을 모두 통과하고 실행기·DB 정리를 마쳐야 한다. 공개 Claude 설치 4개·eval 1개·pipeline 4개와 private pipeline 1개는 이번 실행 범위 밖이다. [CVO3 상세 실행 계획](../../proposals/active/ci-verification-code-organization-phase-cvo3.md)

## Findings and Follow-up

원본 도구 이벤트를 그대로 넣으면 같은 평가 오류가 재현됐다. 명령 필드만 따로 바꿔 대조했다. 이번 경로 확인 구문에 짧은 도우미 이름을 붙인 경우와, 이전에 허용된 구문에 이번 절대경로를 붙인 경우가 각각 거부됐다. 단독 도우미 이름으로 바꾸자 같은 종료 코드·출력·다른 이벤트를 유지한 채 통과했다. 이 대조는 명령 인식만 검증하며 원래 인수 판정을 변경하지 않는다. 후속 작업에서는 신뢰된 도우미의 실제 실행을 회차별로 확인하는 방법을 검토하고, 소스 조회만 한 과거 기록도 음성 대조군으로 유지한다. 이번 검증에서 다루지 않은 전체 인수 항목은 공개 Claude 9개와 private pipeline 1개다. [이전 후보 결과](2026-11-19-cvo3-codex-eval-462f25e.md)
